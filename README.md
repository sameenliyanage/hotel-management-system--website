# Hotel Management System

## Setup

Install dependencies for the backend and frontend:

```powershell
cd "C:\Users\Acer\Documents\VS Projects\Hotel Management System"
npm install
cd client
npm install
```

Seed the SQLite database with sample hotel data:

```powershell
cd "C:\Users\Acer\Documents\VS Projects\Hotel Management System"
npm run seed-db
```

## Run the site

Start the backend and frontend together from the repo root:

```powershell
cd "C:\Users\Acer\Documents\VS Projects\Hotel Management System"
npm run dev:site
```

The launcher automatically chooses a free backend port and points the frontend at it, so it still works if port 3001 is already in use.

Or run them separately in two terminals:

```powershell
cd "C:\Users\Acer\Documents\VS Projects\Hotel Management System"
npm run dev
```

```powershell
cd "C:\Users\Acer\Documents\VS Projects\Hotel Management System\client"
npm run dev
```
